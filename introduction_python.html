6. Generators

They are sometimes useful if you want to create an iterable object by your own and especially if you deal with big data (it is a way to define how to iterate) The syntax is quite similiar to a function, yet we need the “yield” statement. Generators are lazy i.e., the just execute if demanded.

# Example generator

def squared(x=10): # also note that the default argument of the function is fixed to 10 
    for i in range(x):
        yield i**2
generator=squared()
# note that is safes CPU capacity
for i in generator:
    print(i)

7. Error Handling and Control

It is often practical to control the errors of your code in order to be able to identify the root of programming failures, mistakes or wrong input or even allowing to do mistakes.

#float("hello")
# example 

def attempt_float(x):
    try:
        return float(x)
    except:
        return x
    
# the code after "except" will just be executed if an exception occurs.
attempt_float("hello")# we are ignoring any kind of errors here (e.g. ValueError or TypeError)
'hello'
# we can also steer which error should be ignored

def attempt_float(x):
    try: 
        return float(x)
